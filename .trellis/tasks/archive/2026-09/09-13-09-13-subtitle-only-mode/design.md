## 架构（不变）

后端零改动（do_summary=false + force_transcribe 已完整覆盖语义）。纯前端：

```
模式=总结成文（do_summary=true，默认） → 现状全流程
模式=仅生成字幕（do_summary=false）
├─ 来源=自动（force_transcribe=false，默认）：平台字幕优先 → 拿不到/抽查不过自动转录
└─ 来源=直接转录（force_transcribe=true）：跳过平台字幕直接转录
```

## v2 前端方案（HomeAdvancedOptions 内重构处理流程区）

高级选项卡「处理流程」区重排（卡片内容宽 ~950px）：

```
处理流程
┌──────────────────────────────┐  ┌──────────────────────────────┐
│ ◉ 总结成文                    │  │ ○ 仅生成字幕                   │
│   转录/字幕 → AI 总结 → 打标签  │  │   只要字幕文件，不做 AI 总结     │
└──────────────────────────────┘  └──────────────────────────────┘
  ↑ 两张同宽模式卡（复用 adv-switch-tile 视觉语言，选中态高亮）

  仅「仅生成字幕」时显示：
  ┊ 提示块（具体到得到什么/不做什么）：
  ┊ 完成后得到 SRT 字幕 + 转录文本，可在结果页下载；不做 AI 总结、不打标签、
  ┊ 不消耗总结 token。B站字幕拿到后仍做内容抽查（防旧字幕）。

  字幕来源：  (◉ 自动：优先平台字幕，没有就转录)  (○ 直接转录生成)
  ↑ 子选项行，样式对齐现有「校正领域/模型」子选项（虚线上边距）

  ┌ [转录预览 ═○]  ┐  ┌ [说话人分离 ═○] ┐   ← 流程开关改 2 列网格
  │ 仅总结模式显示   │  │                 │      minmax(380px,1fr)
  ┌ [强制转录 ═○]  ┐  ┌ [AI 校正 ═══○] ┐      （4 tile = 2×2，2 tile = 一行两个）
  │ 仅总结模式显示   │  │                 │
```

要点：
1. **模式卡置顶处理流程区**：radio 语义 + 标题 + 一句话说明，与现有 tile 同视觉语言；
   「AI 总结」tile 删除（模式卡取代，单一控制点）。
2. **提示块具体化**（回应"提醒还是不够"）：得到什么（SRT/TXT 可下载）/不做什么（总结/标签/token）/
   抽查仍开——三句话说完，不用去猜。
3. **字幕来源**作模式子选项行（仅字幕模式显示），radio 文案把行为说全。
4. **流程开关 2 列网格** `repeat(auto-fill, minmax(380px, 1fr))`：修复 4 方块挤成窄条；
   窄窗口自动降 1 列。转录预览/强制转录仅总结模式显示。
5. **提交按钮联动**（额外提醒层）：仅字幕模式下「开始处理」→「生成字幕」。
6. HomeInputPanel：**零改动**（已回退，保持纯输入）。
7. settingsStore：重建 jobGoal/subtitleSource computed 映射（单点翻译布尔，store 单测覆盖）；
   useJobRestore/HomeView 提交 payload 零改动（do_summary/force_transcribe 既有字段直读）。
