# 追问对话：多选删除 + 删除确认弹窗

## Goal

追问面板支持「多选删除」：一次勾选多条消息删除，删除前弹确认窗。

## Requirements（用户原话：对话的删除要弹出来多选键，然后删除要确认弹窗）

- 等级 M0：单域（`routers/chat.py` 批量端点 + `ChatPanel.vue` 交互），方案照聊天软件「多选」惯例。
- 现状：消息删除只有**逐条 hover 垃圾桶**（提问=级联删除、回答=单版本），无法一次清多条；单删回答无确认。

## 语义决策

| 项 | 决策 |
|---|---|
| 入口 | 头部新增「多选」按钮（有消息且非流式中可见），点击进入多选模式 |
| 选择粒度 | 消息行：提问行 / 回答行（回答行=该回答，含其全部历史版本） |
| 删除（提问行） | 删**整轮**：该提问 + 其全部回答版本；**不含后续轮次**（多选语境下不得级联误删） |
| 删除（回答行） | 删该回答全部版本；回答全删后其提问成孤儿 → 一并删除（与既有单删孤儿规则一致） |
| 确认 | 删除所选前 `ElMessageBox.confirm` 二次确认，文案说明后果 |
| 既有单删 | 保持不变（提问单删=级联，编辑回填依赖，测试锁定；回答单删=单版本） |
| 批量端点 | `POST /api/jobs/{job_id}/chat/messages/delete` body `{ids:[...]}`，单事务执行，返回实际删除行数 |

## Acceptance Criteria

- [ ] 头部「多选」进入多选模式：每行出现勾选圈、整行可点选、选中行高亮，底部操作条「已选 N 项 / 全选 / 取消 / 删除所选」。
- [ ] 删除所选 → 弹确认窗 → 确认后只删所选：**删中间一轮不伤后续轮次**。
- [ ] 勾选回答行 → 该回答（含 ‹1/2› 全部版本）整条消失；其提问不留孤儿。
- [ ] 流式中 / 无消息时不可进入多选；Esc 退出多选模式。
- [ ] 门禁：pytest / vitest / lint / build 全绿 + OpenAPI 契约重导。

## Notes

- 风险：批量语义与单删不同（提问行不级联）→ 测试锁定「中间轮删除不伤后续」。
- 回滚：新增端点与 UI，回退 commit 即可；无 DB 迁移、无数据格式变化。
