# 质量改进落地

## 需求与授权

落实 `docs/quality-audit-2026-10-07.md` 剩余改进。用户本轮「那你都做吧」确认报告中的范围与建议方案。
风险 M1；形态 Web 全栈，实际改动以后端与验证工具为主，不改公开 API/DB schema。

## 验收

- 同音频同配置命中 ASR 缓存；换 Whisper 档位、云端 provider/model/端点不串结果。
- ASR 缓存记录实际执行引擎；临时降级的结果不会阻止下一次尝试首选引擎。
- 忽略缓存仍跳过读并更新成功结果；免费优先、取消传播及历史任务兼容保持成立。
- Python 静态检查进入 verify 与 CI，真实基线错误修复；超时测试无未等待协程告警。
- 后端运行/开发依赖可复现锁定；退役 B站依赖清理，cryptography 显式声明；锁文件不含私有源/凭证。
- 核对过时任务提交证据后归档，规范基线/CONTEXT/报告更新，索引尽量排除构建产物。
- 全量自动检查及必要的本地真实 API 冒烟通过，每个逻辑单元独立提交。

## 边界与回滚

不修改真实数据库/媒体/模型，不调用付费 API，不 push/发布，不启动新的下载任务。
旧缓存键失效但数据保留；业务/验证工具可按单元 revert。依赖锁从已验证环境解析，并用干净环境核验。
