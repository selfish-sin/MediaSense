# 追问：重新生成按钮挪到提问行 + 任意一轮可重生成

## Goal

「重新生成」从 AI 回答的操作区挪到**提问那一行**（hover 提问时显示），并且**任意一轮**都能重新生成（不只最后一轮），生成该轮的新版本（保留历史版本，沿用变体机制）。

## Requirements

- 用户原话：「重新生成按钮放问句哪里」；澄清后确认 = 挪到提问行 + 任意一轮都能重生（AskUserQuestion 选项一，本轮用户点选）。
- 等级 M1：跨模块（`routers/chat.py` 目标轮定位 + 上下文排序、`ChatPanel.vue` 交互与渲染、新增纯函数 util），方案明确、无需切片。

## 语义决策

| 项 | 决策 |
|---|---|
| 目标轮定位 | 前端带 `user_message_id`（提问行 id）；后端按该行定位该轮现有回答与其变体组。缺省（不传）= 最后一轮，行为与现在完全一致（向后兼容） |
| 新回答落位 | 仍按 id 追加在会话末尾（自动收尾），但**归属该轮**——前端按「轮」归位渲染，后端上下文也按轮排序，故显示与模型上下文都不错位 |
| 模型上下文 | 重生成第 N 轮时：history = 第 N 轮提问**之前**的消息；该提问作为本轮 question 传回（统一走 `regenerate=False` 分支，最后一轮结果与旧实现等价） |
| 联网检索词 | 重生成时用**目标轮的提问**做检索词（旧实现回退用最近一条用户消息，中间轮会搜错问题） |
| 按钮位置 | 提问行 hover 操作区 `复制 / 编辑 / 重新生成 / 删除`；回答行操作区只留 `复制 / 删除`。按钮仅在该轮有回答且非流式时可点 |
| 流式滚动 | 重生成最后一轮 → 跳到最新（现行为）；重生成中间轮 → 滚到该轮，不抢滚动条 |
| 历史版本 | 不变：新回答入组、旧版本转非激活；‹N/M› 切换对任意轮可用（`activate` 端点本就是组作用域） |
| 后续轮次 | 不动（保留原回答）；用户可自行对后续轮继续重生成 |

## Acceptance Criteria

- [x] 提问行 hover 出现 ↻，点它该轮回答原地流式重生成；回答行不再有 ↻
- [x] 中间轮重生成后：新版本显示在该轮位置（不被排到会话末尾）、后续轮次原样保留、刷新后仍正确
- [x] 模型上下文按轮顺序（中间轮新版本紧跟其提问），`_get_session_history` 单测锁定
- [x] 最后一轮重生成行为与旧实现一致（现有 Regression 用例仍绿）
- [x] 门禁：pytest / vitest / lint / build 全绿 + OpenAPI 重导
