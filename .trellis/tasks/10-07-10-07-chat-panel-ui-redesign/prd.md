# 10-07 追问面板 UI 重设计 - PRD

## 需求
我要解决什么问题：追问界面粗糙难看（三层工具栏堆叠、高饱和蓝气泡、一整墙蓝链接、红色删除常驻、悬浮按钮重叠），要求按豆包/DeepSeek 桌面端风格的现代化、简洁精致方向重做。

## 设计依据（2026-10-07 调研）
- setproduct《Designing AI chat interfaces》：避免 SMS 式彩色气泡（用扁平全宽 + 弱背景差）；消息流居中 ~720-768px 阅读宽、line-height≈1.6；流式=闪烁光标；操作按钮 hover 显形；思考过程默认折叠、诚实标注；错误给原因+恢复动作；空态=居中输入+建议 chips。
- Jotform/UXPlanet：克制配色（中性底+单一强调色）、大留白、清晰层级。
- 项目内设计系统：`app-card` 玻璃材质 + `--app-chip-*`/`--app-thinking-*`/`--app-text-*` token（明暗两套自动成立）。

## 具体例子
- 例1：打开有对话的结果页 → 单行纤细头部（追问品牌 + 会话下拉 + 模型下拉 + ⋯菜单），消息区居中窄列，用户消息为弱色调右对齐气泡，AI 回答平铺无气泡 + 底部 hover 操作。
- 例2：引用来源不再是蓝链接墙 → 「已联网检索 · Ollama · 12 条来源」一行状态条，点击展开两列来源卡片栅格。
- 例3：输入区=圆角 Composer（textarea 内嵌 + 底栏：联网模式/思考开关在左，圆形发送按钮在右，Enter 发送提示），流式时变停止按钮。
- 例4：空对话 → 居中欢迎语 + 3 个可点击建议 chips（点击即发送）。

## 验收标准
- [ ] 全部既有功能保留：多会话（切换/新建/重命名/删除）、模型选择、联网三态、思考开关、复制对话、清空、消息复制(仅正文/带来源)/编辑回填/重新生成/删除、时间戳、token 用量、导航轨、流式、跳转最新
- [ ] 三层工具栏收敛为一行头部 + Composer 底栏
- [ ] 明暗两套主题下均成立（只用 --app-* token，不留硬编码色）
- [ ] 用户消息弱化背景色（不再是白字高饱和蓝底）
- [ ] 引用来源改为可折叠卡片栅格（默认折叠，状态条显示条数）
- [ ] 空态有建议 chips；流式有光标与「跳到最新」浮动按钮
- [ ] vitest/lint/build 全绿 + 明暗双主题截图人工验收 + 消息交互 E2E 抽查

## 不做项
- 不改后端契约与 chatExport 导出格式
- 不动 App.vue 主题 token 体系（只消费）
- 不做会话侧边栏抽屉（会话保持下拉切换）
- 不重写 markdown 渲染管线（沿用 useMarkdownListCache/.markdown-body）

## 影响范围
- `frontend/src/components/ChatPanel.vue`（模板+样式重写，逻辑保持）；测试不受影响（chatExport 纯函数未动）。

## 风险与回滚
- 风险等级：M0（单组件、方案明确、无契约变化）
- 回滚：单 commit revert 即可
