# 10-07 重新生成与历史回复版本 - PRD

## 需求
我要解决什么问题：现在点「重新生成」会把旧回答**删掉**再重生成，用户对比不了不同版本的回答。需要像 ChatGPT/豆包那样：重新生成保留旧版本，回答上出现 ‹ 2/3 › 版本切换器，可来回切换查看，且后续追问引用当前选中的版本。

## 具体例子
- 例1：对某回答点「重新生成」→ 旧版本保留，新版本流式上屏，回答头部出现 ‹ 2/3 ›；点 ‹ 可看上一版，点 › 回来。
- 例2：切到第 1 版后继续提问 → AI 的上下文引用的是第 1 版内容（切换持久化，刷新后仍是选中态）。
- 例3：较早轮次的「重新生成」按钮置灰，tooltip 说明只支持最后一轮（与现有「重生成会删除其后全部」的截断语义一致，不做全对话树分支）。

## 验收标准
- [ ] 重新生成不再删除旧回答；同轮回答组成变体组，UI 出现 ‹ N/M › 切换器（仅 M>1 时显示）
- [ ] 切换版本：内容/思考/来源/token/耗时整套切换，并持久化生效版本（刷新后保持）
- [ ] 后续追问的模型上下文只包含「生效版本」，非激活变体不进上下文
- [ ] 旧数据兼容：迁移后存量回答各自成为独立组（单变体），无切换器，行为不变
- [ ] 删除语义：删单条 AI 消息=删当前生效变体（组空连带删问题行防孤儿）；整轮删除/编辑回填=全组+后续
- [ ] 后端 pytest 新增覆盖（迁移/分组/activate/上下文过滤/删除）+ 前端测试 + verify 全绿 + 浏览器实测

## 不做项
- 不做全对话树分支（ChatGPT 完整树形历史）：变体只存在于最后一轮，较早轮重新生成=沿用现截断语义
- 不做多版本变体diff对比视图（只做切换查看）
- 不做「继续生成」（从中断处续写）
- 编辑提问后重发不做变体（沿用现截断语义）

## 影响范围
- 后端：`db/database.py`（job_chats 迁移）、`routers/chat.py`（regenerate 分组、history、activate 端点、上下文过滤、删除语义）
- 前端：`frontend/src/components/ChatPanel.vue`（切换器/regenerate 流程）、`frontend/src/utils/api.js`（activate+stream 参数）
- 契约：`contracts/openapi.json` 重导出

## 风险与回滚
- 风险等级：M1（schema 加列 + API 契约扩展 + SSE 流程调整，方案清晰）
- 迁移为增量加列（try/except ALTER），不可逆风险无；回滚=revert commit（新列留存无害）
