# 设计（M1）

1. ASR 缓存身份在唯一构造函数内版本化：音频哈希、引擎、语言、说话人分离、模型档位、
   设备/平台及相关 provider 的 key/API 姿势/端点/model；只取白名单，不包含密钥。
   一次转录使用同一身份进行读写；实际引擎经内部可选出参记录，不修改三元返回值。
   整条回退到其它引擎的结果可返回用户但不写成首选引擎缓存，避免短暂故障永久降质。
2. ruff 进入 backend verify（包含根工具），先补开发依赖、检查完整基线；自动修复限安全项，
   实质错误逐条核对。统一验证入口拒绝无效目标，不能不跑检查就报成功。
   用例清理被替换 wait_for 接收到的协程，RuntimeWarning 作为失败。
3. requirements.in 保留直接依赖意图；requirements.txt 是生成的完整精确运行锁，
   requirements-dev.in/txt 加测试/检查工具。优先锁已测试版本，更新/干净安装命令写入文档与 CI。
   不冻结整个开发环境，不带 GPU/历史无关包，不含源凭证；启动/打包入口同步锁定安装方式。
   用 lifespan 替换废弃启动事件，兼容新版 TestClient 所需 httpx2。
4. 根据代码、测试和历史提交核对两项 planning 任务，补完成说明后用 Trellis 归档。
   更新 spec 与 CONTEXT，CodeGraph 结论落 task；配置/CLI 不支持的索引边界如实记录。

确认来源：用户确认质量报告全部建议；不改变公共 HTTP 契约，OpenAPI 重导出不适用。
