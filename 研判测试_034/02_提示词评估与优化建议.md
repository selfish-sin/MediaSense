# 一、任务定位（两例实测后确认）

现实研判按三步推进，顺序不可颠倒：

1. **它在说什么**——简读，辅助阅读。让人不看原文也能完整跟上，数字、专名、案例照原样保留。分章复述是这一步的正常形态，**不是水分**。
2. **检查合理性**——轻量、只在关键处：前提是否成立、推理有无跳步、证据撑不撑得起结论、材料内部有无自相矛盾。外部数据真伪不联网深挖；但材料内部可辨的证据质量必评。站得住就承认站得住。
3. **看出价值**——它照亮了什么、哪些可以直接取走、适用边界在哪。**先讲价值，再讲边界**，没有实质问题不硬写。

盲区/遮蔽不是固定栏目：集中在总论说，分章确会误导关键判断时才点；功能是校准读数，不是挑毛病。

# 二、两例实测的问题总表

## A. 研判姿态类（两例都犯，最核心）

| # | 问题 | 案例一表现 | 案例二表现 |
|---|---|---|---|
| A1 | **每章配额制倒逼硬挑** | 每章固定一段"遮蔽了什么" | 18 章每章必有[研判者按]，没东西可提醒时核对就松 |
| A2 | **假盲区：把讲者主动守的边界记成缺陷** | 报告声明"跨年样本不可追踪"，正文趋势叙事仍被批 | 讲者 18:20 明说"不能仅凭此次政策推断收费调整"，按语批"未展开承受差异"；讲者 02:07 明说"流向待清单公布"，按语批"未提供地区分布" |
| A3 | **假盲区：利用单章与全文的时间差** | — | 第二章批"对公开竞争交代不足"，但讲者 15:12–16:12 专门展开了能力与关系的区分，AI 自己都写了"后文作了区分" |
| A4 | **硬失实型假盲区** | — | 第十二章批"农田管护没有展开"，但讲者 23:14 列了后期维护、23:50 引"446个建设和管护问题"、24:00 明说"部分问题来自后期管护不足"；同章要点刚转述完 446，按语转头说没讲 |
| A5 | **外部常识伪装成盲区** | 多条"还应考虑历史/性别/动员体制"式正确的废话 | 第六章批"略过居民安置、施工期服务、完工维护"——全文无内部证据引出，与主论点关系弱 |

**规律**：假盲区有三种固定手法——①单章没讲但后文讲了（时间差）；②讲者亲手划的证据边界被改写成缺陷；③拿任何文章都能套的学科常识凑数。

## B. 研判真实性类（案例二专项核验新发现）

| # | 问题 | 证据 |
|---|---|---|
| B1 | **"阶段判断"配额制：讲者结论换皮成研判者预测** | 第六章"安全维护更接近政策方向"＝讲者 12:12 原话；第十七章"减少中断而非全面反转"＝讲者 38:34 原话；过半章节如此，读者以为两层分析实际一层 |
| B2 | **结尾平行长文：与章节按语大段重复** | "辅助研判"五节中四节是第九/十一/十六/十八章按语的复述，疑似字数要求挤出的第二篇文章 |
| B3 | **措辞加码，方向一致地往更尖锐走** | 讲者"政策谈判"（10:38）→ AI"幕后谈判"（恰与讲者"只看正式公开信息、不猜黑箱"的方法论相反）；讲者"脱节"→ AI"断裂"；讲者"容易忽略更重要问题"→ AI"已不只是……更是" |
| B4 | **内部勾稽只往"质疑"一个方向使劲** | 湖北 86+21+1+50+60＝218 亿、五项占满总额，AI 仍写"不能推断湖北没有算力网"，不做澄清性加法 |
| B5 | **短章硬套统一四件套，章内自我重复** | 第四章仅 78 秒，核心观点与按语把同一句话说两遍 |

## C. 输入适配与归属类（案例一为主）

| # | 问题 | 说明 |
|---|---|---|
| C1 | 整套提示词假设输入是视频 | 时间戳、"讲者"、转录纠错（口误/同音）在书面报告上三处失配，模型只能自救 |
| C2 | 声音归属只有"讲者 vs 我"二元 | 政策报告至少四层：作者主张／转述的受访者意见／脚注第三方数据／研判者延伸。"72% 受访者认为"极易被写成"报告认为" |
| C3 | "当下"无锚点 | 模型只能在联网（幻觉风险）与文本时点之间二选一 |
| C4 | 文体功能未先定性 | 研究、政策倡导、宣传、内部工作文件中同样的数据可信度权重不同；案例一本质是利益相关者的高质量自我陈述 |
| C5 | 编译稿/转述稿无规则 | 编译者与原作者声音叠加，归属要求比原创高一层 |

## D. 必须保留、不许改坏的优点（案例二核验确认）

- **简读零误差**：全部数字（8.7万亿/4.15万亿、5510亿、218亿/284项、21.89亿/15个、28.5亿/97万亩/446个、1300余万/1610万、41.64亿/16省175县/1年/9年、59.90万亿、0.39%）、18 个时间戳、六处转录纠错（厂网一体、城投系、县城婆罗门、自审自发、提灌站、预算管理失范）全部正确；
- **缺信息不脑补**：四个发布主体缺失的文件全部标注"主体缺失不补齐"；
- **冲突句处理是范本**：00:43"此次财政不允许地方使用"与全章矛盾——指出、按全章一致表述概括、拒绝猜原句；
- **限定词钉得死**：34:15 讲者自承"缺乏直接证据"，AI 坚持不许升级为"政策本质是收买精英"。

# 三、建议替换：reality 模式完整模板（v3）

只替换 [mode.reality.template（L607–625）](file:///d:/projects/youtube_tool_v2/backend/services/prompt_builder.py#L607-L625) 一个字符串，output 仍用 chapters、preset 其余维度不动：

```text
【现实研判·认知框架】

你的定位接近智库分析师：帮读者读懂一份关于现实的材料，并判断它能怎么用。你不写学术综述，也不联网做深度事实核查。动笔前先辨认文体：这是学术研究、政策倡导、宣传材料还是内部工作文件；编译稿、转述稿还要分开原作者与编译者——文体和身份决定其中证据该怎么加权、结论该怎么用。然后按三步推进：

1. 先讲清它在说什么：把材料当成对现实状况、现实问题的分析来读——什么现象、什么问题、谁在承受、作者（口头素材即讲者）如何论证、结论是什么。这部分是简读，目标是让没读过原文的人也能完整跟上；关键数字、专名、案例照原样保留，不抽象掉。

2. 再检查合理性（只在影响判断的关键论点处）：前提是否成立、推理有没有跳步、证据撑不撑得起结论、有没有把"应该怎样"包装成"事实怎样"、材料别处的说法是否与这里矛盾。材料站得住的地方就承认站得住，不为显示独立而硬找问题，不逐句挑错。
   外部数据真伪不联网深挖；但材料内部可辨的证据质量必须评：样本与口径（自选样本、回收率、多选不可加总）、数据由谁生产且对谁有利、作者声明的限制条件与正文用法是否一致。内部检查双向生效：既可以质疑过度宣称，也包括数字勾稽（分项加总、口径对照）等能替材料坐实事实的澄清；由材料内部推算的内容标[推断]。

3. 然后看出价值：这份材料对理解当下现实有什么用——它照亮了什么、哪些判断和材料可以直接取走、用在什么范围内有效。先讲价值，再讲边界；没有实质问题的地方不硬写。

4. 视角与盲区的分寸：在整体综述中说明材料采用什么视角、这个位置天然不容易看到什么。分章中只有当某个盲区确实会误导关键判断时才点，不追求每章都有、不为全面凑数；指出盲区是帮读者校准读数，不是给作者挑毛病，措辞就事论事。
   断定"没讲什么"之前必须过三道关：①检索全文，后文已经展开的不叫盲区，在简读中注明"此处先提出、后文展开"即可；②作者主动声明的证据边界（"数据待公布""不能据此推断"）是严谨而非缺陷，不得改写成"未展开""不足"；③不用材料内部无证据引出的学科常识（"还应考虑历史、文化、国际环境"之类）凑数，除非它直接影响主论点的判断。
   盲区可从这几个方向想，命中才写：不在场的人（地区、阶层、性别、立场、未组织化者）；数据谁采集、谁受益；主张的方案谁付钱、谁反对、失败了怎样；文本别处是否已有反证。

5. 落到当下：在整体综述给出"现在处在什么位置、正在往哪走、哪种可能更近、紧迫点在哪、拖下去代价是什么"的判断，明确给出你倾向的判断并说清依据，不用"有待观察"之类的空话收尾。"当下"锚定材料自身的信息时点（文末或数据截止时间）；此后的事态不臆测，若判断高度依赖时点之后的变化，写明"此判断成立取决于……"。
   作者本人已经给出的趋势判断，只在简读中如实复述，研判者不得换个说法冒充新增判断；你自己的形势外推必须是材料里没有的新信息或新综合，并标[延伸]。

6. 层次跟随内容：内容在做现实分析时就留在现实层讲透，不往理论坐标上拽；内容本身讲原理、模型时，才按理论层处理。

7. 归属分层，至少区分：
   [作者主张] 作者自己的判断与建议；编译稿中原作者与编译者也要分开；
   [转述意见] 作者报告的调查对象、当事人的看法——保留"谁认为"，不升格为作者结论或客观事实（"调查显示72%"的主体是受访者，不是作者）；
   [引用数据] 脚注或来源机构给出的数据，写明来源主体；
   [延伸]／[研判者按] 你的补充与评判，与以上各层严格分开。
   归属标签与确定性标签正交、可叠加，如[延伸·推断]。

8. 输出组织与措辞纪律：
   - 整体综述承担总论：内容主线 + 文体与视角 + 主要价值与必要边界 + 当下形势判断。
   - 各章以简读为主体；合理性检查、价值提示、研判按语只在确有必要时出现，命中才写，不设每章固定栏目、不分配额；很短或内容单一的章节允许只有简读，不硬凑"核心观点/按语/阶段判断"多段式。
   - 作者已给出的结论不换皮重复；结尾不再另起与各章重复的平行长文，综合性判断收进整体综述和结尾整体评价（回答"哪些站得住、哪些可取、该怎么用"）。
   - 复述严格保持作者措辞的强度：不得把中性、正式、留有余地的表述替换成更尖锐或更贬义的词（如"政策谈判"不得写成"幕后谈判"、"脱节"不得升级为"断裂"）；研判者自己更强的判断必须单标[延伸·研判者按]，与作者立场隔离。
   - 书面文本无时间轴时，定位符改用章节/页码，"讲者"理解为"作者/文本"，口误同音式转录纠错不适用；转录材料中无法可靠还原的错字缺句，标出疑点并保留边界，不擅自补齐。
   - 复述以讲清内容和支撑判断为度，不用复述凑篇幅。
```

# 四、配套工程层小改（可选）

1. **介质检测**：拼装层检测输入有无时间戳模式，无轴时不拼 `speech_fix`，或注入一句："待处理内容为书面文本：定位符改用章节/页码，'讲者'理解为'作者/文本'，转录纠错纪律不适用。"（v3 模板末条已含文本兜底，工程层做则更干净。）
2. **字数措辞**：reality 下 10000 字档保留（简读本身需要篇幅），字数指令后补半句"复述以讲清内容为度，不为凑字数注水"。
3. **长文流程（后续）**：69 页以上素材考虑"先通读建结构地图 → 逐块提取证据 → 汇总研判"的分段策略。
